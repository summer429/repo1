手機告警測試

點擊按鈕展開手把手流程：先在手機 App 打開推播，再發派一個會刻意失敗的 Agent 任務，確認雲端或筆電上的告警會立刻推到手機。

測試手機告警

完整路徑：手機 App 允許通知 → 發派會刻意失敗的 Agent 任務 → Agent 在雲端或筆電跑出告警並結束這一輪 → 手機立刻收到 App 推播。點通知可回到同一個 Agent。

步驟 1．手機端 App 設定

  1. 在 iPhone 或 iPad 從 App Store 安裝 Cursor（iOS／iPadOS 26.0 以上）。Android 請用 Chrome 開啟 cursor.com/agents，再點「Install App」裝成 PWA。
  2. 用與電腦相同的 Cursor 帳號登入。公司若要求 SSO，就走 SSO。
  3. App 第一次詢問通知時按允許。若當時按了稍後，到手機「設定 → 通知 → Cursor」打開「允許通知」，並打開鎖定畫面、通知中心、橫幅與聲音。
  4. 同一頁打開 Live Activities（鎖定畫面與動態島最多可同時追蹤 8 個 Agent）。
  5. 關閉勿擾，或把 Cursor 加進允許通知的 App。背景 App 重新整理維持開啟。
  6. 帳號須為含 Cloud Agents 的方案（Pro、Pro+、Ultra、Teams、Enterprise）。隱私模式請使用 Privacy Mode；Legacy Privacy Mode 無法在手機啟動 Agent。
  7. 打開 App，確認看得到要測試的儲存庫與分支。Teams 帳號請登入同一個團隊，Agent 清單才會對得上。

送出任務後把 App 切到背景或鎖定螢幕。App 留在前景時，系統通常只更新畫面，橫幅推播會晚一點才出現。

步驟 2．選定 Agent 跑在雲端或筆電

雲端

  1. 在電腦的 Agents 視窗，或開啟 cursor.com/agents。
  2. 輸入框下方選 Cloud，指定這個儲存庫與分支。
  3. 也可以直接在手機 App 選儲存庫後送出下面的測試任務。雲端機器會繼續跑，手機鎖定也沒關係。

筆電（Remote Control）

  1. 電腦安裝 Cursor 3.9.8 或更新版本。
  2. Agents 視窗開啟 Settings → Agents → Remote Control。需要的話一併打開「Keep this computer awake」。
  3. Teams／Enterprise 請管理員先到 Dashboard → Cloud Agents → Self-Hosted 啟用 Remote Control。
  4. 在本機 Agent 輸入框執行 /remote-control，下一則訊息再貼上步驟 3 的任務。
  5. 工具指令跑在這台電腦上，所以電腦要保持開機、聯網、不要睡眠。工作階段會出現在手機收件匣。

步驟 3．發派會刻意觸發錯誤的任務

把下面整段貼進 Agent 後送出。它只執行一個必定以 exit code 2 結束的指令，然後立刻停止，讓這一輪以告警狀態結束。Cursor 會在 Agent 結束這一輪時發送推播。

【手機告警測試｜請刻意失敗並立刻結束】

這是一則推播測試，請嚴格只做下面三件事，然後結束這一輪：

1. 在終端機執行這段一定會失敗的指令（不要改寫、不要重跑）：
   node -e "console.error('MOBILE_ALERT_TEST: intentional failure'); process.exit(2)"

2. 確認行程以 exit code 2 結束。若環境沒有 node，改執行：
   python3 -c "import sys; sys.stderr.write('MOBILE_ALERT_TEST: intentional failure\n'); sys.exit(2)"

3. 不要修復、不要重試、不要修改任何檔案、不要 commit、不要開 pull request。
   立刻停止，並用下面這段當回覆的第一行：

   【告警】手機推播測試：刻意觸發的指令失敗（exit code 2）

   接著只列出三行：失敗指令、exit code、錯誤訊息原文。

步驟 4．確認手機立刻收到推播

  1. 送出後立刻鎖定手機，或把 Cursor App 切到背景。
  2. 雲端或筆電上的 Agent 跑完那個失敗指令，回覆以「【告警】手機推播測試…」開頭並結束這一輪。
  3. 鎖定畫面應出現 Cursor 推播；若有 Live Activity，狀態會從進行中變成這一輪已結束。
  4. 點推播應打開同一個 Agent，內文看得到 exit code 2 與 MOBILE_ALERT_TEST: intentional failure。

你應該看到：Agent 在雲端或筆電跑出告警 → 手機立刻收到 App 推播通知。

若鎖定畫面沒有橫幅，依序檢查：

  • 「設定 → 通知 → Cursor」的允許通知、橫幅、鎖定畫面為開啟。
  • 這次任務是 Cloud，或已用 /remote-control 交給手機。只留在本機、沒有交出的 Agent 不會進入手機收件匣。
  • 手機與電腦是同一個帳號；Teams 要在同一個團隊。
  • 電腦在 Remote Control 測試時保持醒著且有網路。
  • 打開 App 的收件匣，確認該 Agent 已以告警內容結束。推播對應的是「這一輪結束」。
